# INI → DSMT 匯入資料

來源：`DSMT/VoiceCommands.ini`。本目錄由 BuildLatestModel.cmd 更新。

開啟 Working 內的對應原生工程，選擇需要更新的群組，清空該組詞條後，以「批次新增」讀取同名 `.BatchAdd.txt`；完成後儲存工程。群組設定及順序沿用原工程。

`.txt` 含官方群組 XML 設定，供「群組 → 匯入群組」使用；`.BatchAdd.txt` 僅含詞條，供現有群組的「批次新增」使用。兩者均為 UTF-16LE。

詳細操作：[DSMT 操作教學](../../DSMT_OPERATION_GUIDE.md)。
